# World Atlas0.4.10 for SillyTavern

Мобильный атлас с30 русскими карточками миров, ручным путём и необязательной интеграцией WorldMemory: маршрут игрока и календарь по сохранённым L0. Серверный plugin, сборка и npm install не нужны.

## Установка и обновление

В SillyTavern: **Расширения → Установить расширение**. Вставьте:

```text
https://github.com/Ilya626/Extension-WorldAtlas
```

Перезагрузите ST. Открыть: меню расширений рядом с полем ввода → **Атлас миров**. Прямая ссылка: `/#world-atlas`. Обновление: менеджер расширений ST → World Atlas → обновить → перезагрузить. Вручную: клонируйте репозиторий в `SillyTavern/public/scripts/extensions/third-party/Extension-WorldAtlas`; далее `git pull`. Для пользовательской установки ST менеджер сам выбирает каталог.

### Ручная привязка календарного события

В календаре нажмите **Выбрать планету** у записи без точки на карте. Откроется выбор из точек этой игры и полной загруженной фоновой базы; поиск использует имеющиеся русские и английские названия и aliases. Выберите точку и нажмите **Привязать запись**. Фоновая точка добавляется только в текущий чат. У связанной записи доступны **На карте**, **Изменить привязку**, **Снять ручную привязку** и **Отменить** последнее действие.

Исходное место, дата, час и источник остаются прежними; L0 и WI не редактируются, глобальный alias не создаётся. Привязка сохраняется в metadata текущего чата и имеет приоритет над модельным выбором. Изменение даты, порядка выдачи или названия планеты моделью её не стирает. При изменении подтверждающей цитаты выбор сохраняется только при однозначном перекрытии прежнего и нового фрагментов того же неизменённого источника; при правке источника или неоднозначности не переносится на другой эпизод. Неизвестная дата остаётся неизвестной. Старое событие уточняет историю; только последнее уже подтверждённое прибытие уточняет текущий маркер. Привязка записи без прибытия не создаёт новое перемещение.

### Оценка перелёта

Нажмите **Оценить перелёт** на карте или **Перелёт сюда** в карточке. Отправление подставляется из текущего положения, но можно выбрать любые два мира. Укажите регионы, класс гипердвигателя и при необходимости день/время вылета. Для игровых миров регион по знакомому ориентиру помечен как предположение; неизвестный регион выбирается вручную.

Используется одна справочная **игровая шкала [SW5e](https://sw5e.com/rules/sotg/adventuring)**: направленная таблица регионов × класс двигателя. Меньший класс быстрее. Это не каноническая длительность перелётов и не перевод пикселей карты в часы; задержки, местный подъезд и поправки астрогации не включены. Можно скопировать готовую фразу для мастера. Ожидаемая дата остаётся планом: карта не переносит игрока и не меняет сыгранные события или календарь.

Личный короткий импорт может передавать `travelDefaults: { "hyperdriveClass": 2 }` для известного текущего корабля; игрок свободно выбирает другой двигатель. Без такого поля используется явно обозначенное допущение ×1. Личные данные корабля в поставку не входят. Расчёт работает локально без API.

### Карта и источники

30 карточек и изображения доступны сразу, без WorldMemory, ключей и сети. В поставке они размещены на **условной сетке каталога, не географической карте**. Это самостоятельный рабочий просмотрщик: поиск RU/EN, список, карточки, перемещение/масштаб и ручные отметки. До загрузки геослоя линия между отметками не рисуется как существующая гиперлиния.

Для полной справочной карты нажмите **Карта из источника** внизу атласа. Браузер отдельно загрузит два GeoJSON из закреплённого public snapshot iSkore / Henry Bernberg / CARTO на `raw.githubusercontent.com`. Получатся2466 точек (30 карточек +2436 фоновых) и1573 составляющие гиперлиний. Данные сохранятся в настройках текущего пользователя ST; повторная загрузка и модель не нужны. При сетевой ошибке каталог остаётся доступен. Существующие локальные карты сохраняются при обновлении.

Поиск охватывает **все именованные точки загруженного геослоя**, включая миры без готовой карточки. Одноимённые точки различаются по региону и grid; результаты выдаются порциями по50 с общим числом и кнопкой «Показать ещё». Выбор добавляет активную точку с исходными координатами и подсвечивает проходящие рядом исходные гиперлинии; остальные миры остаются лёгким фоном. Новые соединения не придумываются. Выбранные точки сохраняются после перезагрузки ST. Для мира без подробной карточки показаны только данные источника. Просмотр не меняет маршрут, положение игрока или календарь.

**Геоданные не входят ни в релиз, ни в историю public Git.** Отдельное разрешение исходных правообладателей картографии не установлено; MIT upstream относится к ПО и не объявляется лицензией карт. Внешняя загрузка не даёт дополнительных прав на распространение. Источники, решение по правам и офлайн-подготовка своего JSON: [data/provenance](data/provenance/README.md). Можно импортировать собственную карту через **Карта JSON**. Автоматических внешних загрузок нет.

Красный путь полной карты следует существующей сети. Старые участки остаются тёмно-красными, новые ярче; прозрачность постоянна. Разрыв показан явно, координаты неизвестных мест не угадываются. Декоративный Млечный Путь не привязан к географии Star Wars. Сеть источника смешивает эпохи Canon/Legends и не удостоверяет доступность маршрута в22ДБЯ.

## Самостоятельный режим

WorldMemory не обязателен. Откройте чат для сохранения пути, нажмите **Линия пути**, выберите карточку и добавьте остановку. **↶** убирает последнюю, **Очистить** сбрасывает путь; положение камеры сохраняется при возврате из чата. Предпросмотр `/scripts/extensions/third-party/Extension-WorldAtlas/preview.html` работает без чата, его изменения остаются в открытой странице.

## Импорт короткого маршрута и календаря

Откройте нужный чат → меню расширений у поля сообщения → **World Atlas: импорт маршрута / JSON**. Такой же вход есть в настройках World Atlas и внутри карты: **Импорт маршрута и календаря**. Это импорт короткого маршрута в открытый чат; кнопка **Карта JSON** отдельно меняет саму карту.

На экране импорта два способа: **выбрать файл любого типа** или **вставить JSON текстом → Импортировать JSON**. У файлового поля нет accept/MIME/capture-фильтров. Если Android всё равно открывает фото, откройте короткий JSON как текст в файловом менеджере/редакторе, скопируйте всё содержимое и вставьте в поле. Чтение буфера через API и отдельное разрешение не нужны. Оба способа используют один проверяющий парсер; ошибочный или слишком большой файл/текст не заменяет прежний путь. Сообщение об ошибке остаётся рядом с полем, вставленный текст сохраняется для исправления.

Переносятся только события, рассчитанные даты, опора и граница сохранённого участка. Карточка персонажа, WI, тексты сообщений и архив L0 не импортируются. Локальные L0 IDs могут отличаться или отсутствовать: импортированная база не удаляется. Срез и неучтённый хвост подписаны явно. **Отменить импорт** возвращает предыдущее состояние Atlas, включая автоматический/ручной режим.

С установленным WM новые L0, целиком следующие за границей среза, автоматически добавляются к базе без дополнительного запроса. Их даты рассчитывает календарный модуль WM от импортированной даты и опоры. Старые посещения не дублируются; откат нового L0 убирает только его добавления. Для сопоставления используются отпечатки последних сообщений среза, а не UUID L0. Если исходные сообщения не найдены однозначно, импорт явно привязывает продолжение к концу открытого чата на момент импорта: полный старый чат не нужен. Если эта локальная граница позже удалена/изменена либо новый L0 перекрывает границу, Atlas показывает причину. В перекрывающем L0 новые подтверждённые места сохраняются, а неотделяемое прошедшее время отмечается неизвестным; эта неопределённость сохраняется и после следующих L0. При откате самой истории за импортированную границу маркер текущего места снимается; импортированные события остаются историческим срезом. Неполные даты сохраняют неизвестные интервалы.

Когда в обновлённом atlas JSON появляется карточка ранее ненанесённого места, сохранённые названия заново сопоставляются с ней. Координаты из совпадения похожих названий не придумываются. До появления достоверной точки место остаётся в списке и календаре без линии и текущего маркера. **Использовать местные L0** в сведениях отключает импортированную базу и возвращает обычную местную историю. Опора местной игры и её архив при импорте не переписываются.

## Интеграция WorldMemory

Для подготовки новых L0 от импортированной даты требуется [WorldMemory0.5.30+](https://github.com/Ilya626/Extension-WorldMemory). Atlas читает его публичное состояние и готовый `timeline` из того же ответа создания L0: дату/точность, прошедшее время и реальные места игрока. Отдельного запроса на каждый ход нет. Файлов или установки WM для самого просмотрщика не требуется.

**Обновить маршрут** открывает один компактный экран. Вкладки **Маршрут / Календарь** сразу под шапкой; подключение и источники свёрнуты в **Настройки и сведения**. Положение подписано **По L0 до сообщения…**: несжатый хвост пока не меняет маркер и календарь. Планы, воспоминания, упоминания и поездки NPC не считаются перемещением игрока.

Для старых L0 без timeline кнопка предлагает один OpenAI-compatible запрос на весь доступный legacy-пакет. До вызова показаны объём и лимит ответа, после — доступный provider usage. Собственные URL/модель/ключ можно указать здесь же или использовать подключение WM; встроенной платной модели/endpoint/ключа нет. Повторный клик с теми же источниками использует сохранённый результат, автоматических повторов нет. При ошибке прежние данные сохраняются; неизвестная денежная цена не выдумывается.

Источники сохраняют L0/sourceIDs/ревизию/цитату. Правка/откат исключают недействительные производные. Ручной путь имеет приоритет; **Использовать историю** возвращает автоматический, **Отменить обновление** восстанавливает предыдущий снимок. Ненанесённое последнее место и незавершённый перелёт показываются явно; последняя нанесённая планета не выдаётся за текущую.

## Календарь

Кнопка **▦ Календарь** находится прямо в строке поиска карты. Нижний лист показывает месяц, дни с событиями и выбор **День / Период**. Нажмите день, чтобы увидеть его события; **На карте ↗** открывает соответствующее место. Просмотр прошлой даты сохраняет текущее положение игрока. **К последнему** возвращает к последнему сохранённому дню. `≥` означает минимальную дату при неизвестном интервале, `≈` — приблизительность; это не точная дата. Профиль и ограничения доступны в свёрнутой опоре.

**Обновить календарь LLM** находится сразу под поиском на основном экране атласа. Та же операция доступна в календаре как **Уточнить календарь моделью**. Если нет WorldMemory0.5.35+ или открытого чата, кнопка остаётся видимой, а рядом написана причина. Ошибка подключения показывается рядом после нажатия. Обновление использует один запрос через подключение резюмирования WorldMemory. Модель читает выбранные L0, их полные исходные сообщения и календарную опору, затем уточняет даты и сыгранные перемещения. Чат, тексты L0, WI и начало игры сохраняются. Во время запроса доступна **Остановить**. Ошибка или изменение истории сохраняет прежний календарь; неподтверждённые исправления отдельного L0 не стирают его прежние данные. Старый снимок игры импортировать не требуется. Автоматическое локальное восстановление уже сохранённых ответов выполняется без вызова модели.

Начало и профиль задаются для каждой игры. WM и Atlas используют одну опору и накопленное время; следующий L0 получает предыдущую рассчитанную дату и длины календарных единиц. «Следующее утро» продвигает календарный день, точный час без основания не задаётся. Неизвестные старые интервалы сохраняют явную нижнюю границу.

Есть универсальный профиль и **ЗВ · Legends368**:5дней в неделе,10месяцев по35дней и18внемесячных дней. В скобках — привычные названия **того же момента** с игровым годом ДБЯ/ПБЯ; это адаптация подписей, не Gregorian-конверсия. Например,35января допустимо. Три местных праздника условно размещены в конце года — игровая договорённость. Стартовый номер дня задаёт игрок; каноническая дата Геонозиса не выдумывается. Canon365/12месяцев не смешивается с этим профилем. Источники: [Standard Units](https://www.theforce.net/swtc/units.html), [Galactic standard calendar](https://starwars.archivum.wiki/article/galactic_standard_calendar).

Короткий файл может содержать отдельные **игровые места** этого чата. Они не меняют установленный каталог и не становятся каноническими мирами. Если задан только сектор, отметка у его ориентира явно условная. Существующая гиперсеть подсвечивается до известного ориентира; пунктир показывает только условный подъезд от него к игровой отметке. Прежние участки пути сохраняют тёмно-красную подсветку. Место без координат остаётся доступным как карточка и в поиске. Отмена импорта возвращает прежний слой игровых мест. Названия, описания и опоры таких миров находятся только в личном файле/metadata чата.

## Своя карта и разработка

`data/star-wars-22bby.json` задаёт оформление, `data/planet-cards-30.json` —30 авторских пересказов со ссылками. Для другого мира импортируйте atlas JSON: `id`, `title`, `width/height`, `places` с уникальными `id`, именем, `shortText` и `x/y`. Необязательный `context:{points,paths}` задаёт фон/сеть; `paths[].points` — массивы `[x,y]`. Изображения локальные относительно аддона или встроенные PNG/JPEG/WebP. Лимит JSON8МБ, активных точек10000. Reader не содержит заданной вселенной или игрового старта.

Исходная картография в Git не хранится. [Офлайн-конвертер](scripts/prepare-reference-data.mjs) создаёт локальный импортируемый пакет из отдельно полученных исходников; он не обращается к сети. Существующие9 интеграционных тестов запускаются при соседнем checkout WorldMemory: `node --test tests/history-route.test.mjs`. Они используют модули WM только как тестовый fixture; runtime Atlas их не импортирует.
