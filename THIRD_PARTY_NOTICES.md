The galaxy background is an artist's conception of the Milky Way, used as a decorative galaxy. Planet illustrations are generic artistic depictions, not canonical Star Wars imagery. The MIT code license does not relicense these assets.

The Star Wars card pack contains30 author-written Russian cards with source links, not private play history. Its bundled positions are an original catalogue grid, not geographic coordinates. Third-party reference geometry is NOT included in the release or its public Git history. Users can fetch the pinned iSkore / Henry Bernberg / CARTO source separately or import their own map; see data/provenance/README.md.
